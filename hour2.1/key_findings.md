# Hour 2.1 — Key Findings

1. **Overload → Fatigue link is weak (r = 0.07)** — consistent with hour2 regression finding; digital overload does not strongly drive fatigue at the aggregate level

2. **Fatigue → Print_Trust link is minimal (r = 0.03)** — fatigue alone does not flip consumers to print; the switching mechanism is more complex

3. **Privacy Concern moderates the Overload → Trust path (Δr = 0.15)** — correlation rises from r=0.02 (low privacy) to r=0.17 (high privacy); visible moderation effect confirming the Privacy Multiplier from hour2

4. **Overload → Print_Comprehension link is near-zero (r = 0.03)** — digital overload does not improve perceived print comprehension directly

5. **Combined read with hour1.1 clusters:** the high-overload Cluster 0 shows elevated Print_Trust (3.36) — the segment most likely to be converted through a privacy-led narrative
